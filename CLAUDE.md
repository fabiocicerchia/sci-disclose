# CLAUDE.md

Guidance for Claude Code (and other AI agents) working in this repo.

## Project

`sci-disclose` measures the **Software Carbon Intensity** (Green Software
Foundation spec, ISO/IEC 21031:2024) of something you can point at: a command,
a script, a function, a repo, or a manifest you declare. Go, single `main`
package at the repo root, binary named `sci`. `gopkg.in/yaml.v3` is the only
dependency, and it exists for the manifest targets alone.

Where things live: `sci.go` the equation, `energy.go` the RAPL and modelled
backends, `intensity.go` the grid lookup and its offline fallback,
`coefficients.go` the published constants, `manifest.go` the declared-workload
path, `harness.go` the per-language function harnesses, `report.go` the
disclosure output, `main.go` the CLI.

## Commands

```sh
make help     # every verb this repo exposes
make build    # compile ./sci
make install  # go install .
make test     # go test -race ./...
make lint     # go vet + gofmt check
make fmt      # gofmt -w .
make setup    # install the pre-commit hook
make check    # run all pre-commit checks on the whole tree
make clean    # remove the binary
```

## Conventions

- SCI is a **rate**, not a total. Nothing here infers carbon from source code
  alone — a target either runs a workload and is measured, or declares one in a
  manifest. Don't add a path that guesses.
- Every number in a report carries its provenance (`[measured]`, `[model]`,
  the API reading and its window). A new coefficient or backend ships with the
  source it came from, and `sci coefficients` prints it.
- Every assumption is overridable by a flag, and the report states the value it
  used. The physical world needs tuning a model cannot see.
- Match existing style; don't reformat unrelated code.
- Conventional Commits for messages (see CONTRIBUTING.md).
- `CHANGELOG.md` is generated by release-please — don't hand-edit it.
- Never commit secrets; CI runs gitleaks.

## Tooling

The GitHub workflows, `.pre-commit-config.yaml`, `.editorconfig` and
`SECURITY.md` are shared config, kept identical across the portfolio. A local
edit here is drift and the next sync overwrites it.

- Hooks are pinned by commit SHA with the tag in a trailing comment. A tag can
  be moved, a SHA cannot.
- `pre-commit install` once per clone. Don't add a `.githooks/` directory:
  `core.hooksPath` replaces `.git/hooks/` wholesale, so setting it silently
  stops every pre-commit hook from running.
- CI runs this same `.pre-commit-config.yaml` through `pre-commit/action`, so
  what passes locally is what gates the pull request.

## Guardrails

- Don't add dependencies. The one that exists is already one more than ideal.
- The RAPL counter arithmetic is tested against a fake `powercap` tree and has
  never read a real one — see the roadmap. Don't claim otherwise in docs.
- Ask before large refactors or destructive operations.
